# Third-Party Notices

## Cockatrice

The generated database targets Cockatrice card database version 4. The test fixture `WLX/source/automation/tests/cards_v4.xsd` is a vendored copy of the Cockatrice project's official schema and remains subject to the Cockatrice project's licensing terms.

Source: <https://github.com/Cockatrice/Cockatrice/blob/master/doc/carddatabase_v4/cards.xsd>

The WLX desktop shortcut icon is a monochrome derivative of the Cockatrice project's official website favicon. The original white Cockatrice silhouette is retained and the green field is recolored black.

Icon source: <https://github.com/Cockatrice/cockatrice.github.io/blob/master/favicon.svg>

This project is independent of and is not endorsed by the Cockatrice project.

## Scryfall

The publisher queries Scryfall's named-card API only to verify the exact identity of official Magic cards and to prevent original custom cards from reusing an official name. It does not import official card rules into original WLX cards.

Scryfall: <https://scryfall.com/docs/api>
